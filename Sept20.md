## SERVER SIDE RENDERING :
          1.   we use server side rendering for using server side code to dynamically display different data when needed.generally pulled out of database stored on server and sent to the client to displayed via based on the code that written on server side.

          2. Every time the user visits a new page on the site, the server will repeat the entire process.

          3.Its basically mechanism that allows server to store information associated with current user of site and send difference response based on the information from client side server.

          4.In this you can control the access  of user  to restrict the authorized user and give information which user is permitted  to view.

          5.server can store the information of user and give more information based on the  previous use of user and based on that it will provide better experience when the same user visit.

          6.Advantages:

                 1.Faster initial load times.
                 2.Improved SEO optimization.
                 3.Can provide a better user experience for users with slower internet connections .
            
          7.Disadvantages:

                 1.require more server resources and maintenance.This can result in slower subsequent page loads if the client needs to make additional server requests.
